# Boat Cover Measuring Guide — Get the Perfect Fit Every Time

Boat cover fit problems — wind lift, water pooling, and access issues — trace back to measurement errors. Here's the complete measuring process.

## Tools You Need

- Measuring tape (100" minimum)
- Helper or notebook
- Photos of the boat from multiple angles

## The Three Critical Measurements

**Centerline length:** From the bow tip (at the waterline level) to the stern edge, along the centerline. Do NOT include swim platforms, outboard motors, or bow rails — measure these separately.

**Beam width:** The widest point of the hull, measured gunwale to gunwale. For trailered boats, measure at the widest part of the boat, not the trailer.

**Gunwale height:** From the gunwale up to the tallest fixed point — windshield, T-top, or tower.

## Accessories That Change the Fit

| Accessory | Measurement Needed |
|-----------|-------------------|
| Swim platform | Width and protrusion distance |
| Outboard motor | Height when tilted down |
| Bow rails | Height and length |
| T-top / tower | Overall height from gunwale |
| Downriggers | Height and spread |

## The Sizing Formula

For a standard cover:
```
Length = centerline length + 12" (for overhang)
Width = beam + 12" (for overhang)  
Height = gunwale height + 4-6" (for clearance)
```

## Common Mistakes

1. **Measuring the trailer, not the boat** — the trailer adds 6-12 inches
2. **Forgetting the swim platform** — covers that don't extend over the platform leave it exposed
3. **Ignoring the T-top height** — the tallest fixed point determines the height
4. **Not accounting for accessories** — add 4-6 inches for each mounted accessory

## Custom vs Universal

Universal covers fit boats within a size range and are cheaper. Custom covers are made to your exact measurements — the right choice when you have a T-top, tower, or unusual hull shape.
